# Web Toys

Small single-page web apps, each self-contained in its own folder. Open the `index.html` in a browser.

| Folder | What it does |
|---|---|
| `hindi-lyric-generator/` | Generates Hindi song lyrics from templates |
| `notes-to-calendar/` | Turns photos of handwritten notes into calendar events (OpenAI vision) |
| `device-usage-tracker/` | Daily screen-time tracker |
| `kdp-ads-optimizer/` | Amazon KDP ads campaign calculator for low-content books |
| `word-processor/` | Browser-based word processor |
